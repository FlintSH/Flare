# Meticulous visual tests

The current guide lives in the public handbook:
[Local visual testing with Meticulous](site/contributing.md#local-visual-testing-with-meticulous).

Meticulous's hosted CI workflow has been retired. The CLI, repository skills,
recorders, and disposable Docker test image remain available for local visual
checks. The handbook covers setup, authenticated recording, local replay and
screenshot comparisons, service-access limits, and cleanup of old GitHub required
checks and the unused Actions secret.
